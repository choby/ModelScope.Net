# P0-07 威胁模型与安全评审材料

版本：draft-1，2026-09-05。工程材料已形成；安全批准尚未完成。范围是既定 Hub、多运行时、宿主网关和部署边界，不等同于生产安全认证。

## 资产与信任边界

受保护资产：Hub凭据、用户输入/输出、私有模型身份、模型及Catalog完整性、宿主文件和网络权限、CPU/内存/GPU可用性、认证及审计证据。

边界：ModelScope仓库→Hub下载器→只读快照；签名发布清单→生产路由；宿主→本地Python/llama子进程；网关→跨主机mTLS Worker；宿主→Remote API；工作负载→Kubernetes节点/CNI；认证流水线→签名发布控制面。

仓库文件、模型代码、HTTP响应、推理输入和子进程输出均按不可信数据处理。应用部署代码、Catalog公钥配置、运行时包摘要来源和集群控制面属于受信基座，必须受版本/权限管理。

## 威胁与控制

| 威胁 | 控制及代码/证据 | 未关闭的验证 |
|---|---|---|
| 凭据泄漏 | CredentialStore原子写入与用户权限；ENV-01/02环境白名单；LOG-01输出限额与脱敏；Telemetry哨兵测试 | Windows生产凭据权限及真实私库运行 |
| 伪造/替换模型制品 | 下载SHA及原子提交；Catalog RSA-PSS验签；ProductionRuntimePolicy精确绑定并复核Hash | 生产签名密钥托管、轮换与吊销流程实测 |
| 使用同ID未认证Commit | 生产路由核对完整Commit/任务/平台/运行时摘要；会话限制任务，缓存键含任务/代码标记 | P5撤销分发及池换代自动化 |
| 偷偷把输入发给远程服务 | 自动Remote默认关闭；显式选择或AllowRemoteFallback；自定义远程插件标记 | 目标集群出网策略实测 |
| 任意代码执行/提权 | CODE-01默认拒绝；PATH-01模型根；ARG-01关键参数不可覆盖；OS-01非root/capabilities/seccomp | 实际目标内核、RuntimeClass、容器运行时验证 |
| 读取或修改宿主文件 | FS-01只读根/模型卷、有限临时目录；Hub路径校验与离线身份匹配 | 目标PVC、符号链接只读范围及存储权限 |
| Worker身份冒用 | NET-01回环；AUTH-01临时随机密钥；TLS-01与MTLS-01；匿名客户端拒绝测试 | 集群证书发放、轮换、过期和吊销演练 |
| 内存/CPU/PID耗尽 | QUOTA-01、RESOURCE-01、资源池并发/队列/估算内存；PROC-01子进程树清理 | 节点PID配置、GPU/显存限额及真实72小时容量 |
| 失败发布持续服务 | P4-06试调用、逐级放量、运行失败撤回、数值阻断、撤销、旧请求排空 | 多副本一致发布、告警和生产集群回滚 |
| 用过期/伪造测试冒充认证 | 固定Revision报告回链；新的签名策略；演练标明平台/范围 | P5持续认证、证据时效、签名撤销控制面 |

完整控制编号见 deployment/worker-security-matrix.json。该矩阵的部署控制通过表示清单及已有本机检查通过；不能证明目标CNI、节点PID和GPU配置实际生效。

## 安全批准所需附件

固定发布模型及许可证清单、冻结硬件/运行时矩阵、全部制品和镜像摘要、依赖扫描、签名信任根管理说明、真实权限与网络负面测试、资源耗尽/故障恢复报告、72小时SLO报告、灰度回滚报告、审计脱敏报告。

审查记录必须包含审查人、角色、时间、清单版本/摘要、证据路径、发现项与处理决定。产品/技术/安全/法务的 pending 不得由工具自动改成 approved。当前没有可据以完成 P0-07/P0-08/P4-08 的批准记录。
